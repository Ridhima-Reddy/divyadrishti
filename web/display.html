  1. Sign this screen in as your shop. Using one computer for everything? In the optical store app, choose Use this computer as the test screen: it opens this page already signed in.
  2. Set the screen size once by holding a bank card against the screen, so the letters show at their true size.
  3. Place the screen 3 m or 6 m from the patient. In a 3 m room, use a mirror for 6 m.
  4. When a patient’s tests start, a QR code appears here. The patient scans it with their phone camera, with nothing to install, and answers on the phone. The code stops working when their tests end.
